# Phase 0 — Les meilleures ressources gratuites utilisables

Vérifié le 25/11/2026 sur les pages officielles (sauf mention « à confirmer »). Règle retenue pour le dépôt public : **uniquement CC0, ou CC-BY (crédit obligatoire)**. Pas de licence « non commerciale », pas de « partage à l'identique » (CC-BY-SA) pour les fichiers du jeu, pas de licence qui interdit de republier les fichiers bruts (le dépôt GitHub public les republie).

Légende qualité : ★ faible · ★★ correcte · ★★★ très bonne · ★★★★ excellente (proche du jeu commercial).
